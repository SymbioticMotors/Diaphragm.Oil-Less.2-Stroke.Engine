# Diaphragm.Oil-Less.2-Stroke.Engine
Has a flexible diaphragm that separates the crankcase from the intake air compression chamber allowing it to run without an oil fuel mixture containing all lubricating oil in the crankcase. This was an innovation from a Japanese inventor that never made it to market. https://www.google.com/search?q=2+stroke+engine+crankcase+diaphragm+oilless
